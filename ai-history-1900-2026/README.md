# 一个问题的一百二十六年

人工智能简史 1900—2026 · 竖屏 9:16 动画短片 · 2 分 56 秒 · 带配乐

主角是一个问题。1900 年希尔伯特问「思考能不能变成机械步骤」，1950 年图灵问「机器能思考吗？」，那个琥珀色的问号贯穿全片，最后变成一个闪烁的光标，留给观众。

画面、字体和配乐跟着年代一起变：默片字幕卡、构成主义海报、蓝图、打字机、瑞士海报、绿色荧光屏、冰冻的「缓冲中」、琥珀色像素屏，一直到今天的聊天界面。

| `src/` | 影片源码：`engine.js`（渲染引擎、文字动画、特效、转场）、`scenes1–3.js`（27 个镜头）、`player.js`（播放器与离线渲染接口）、`shell.html`（页面外壳） |

整部片子的每一帧都是时间 `t` 的纯函数，所以同一份代码既能在浏览器里实时播放，也能被无头浏览器逐帧离线渲染。

## 重新构建

需要 Node 18+、Python 3（`numpy`、`scipy`）、带 libx264 与 aac 的 ffmpeg，以及 Playwright 的 Chromium。字体来自 Google Fonts，渲染时需要联网。以下命令都在本目录下运行。

```bash
cd ai-history-1900-2026
npm install
node build.js                 # 由 src/ 生成 film.html 和本地预览用的 film-local.html
node cues.js                  # 导出音效时间轴 cues.json
python3 music.py              # 合成 soundtrack.wav
node render.js                # 逐帧渲染并混入音频，输出 film.mp4
```

`render.js` 可用环境变量调整：`FPS`（默认 30，成片用的是 `FPS=60`）、`WORKERS`（并行页面数，默认 4）、`T0`/`T1`（只渲染一段）、`OUT`（输出文件名）、`FFMPEG`（ffmpeg 路径）。

`node preview.js "12,50,110" sheet.png` 可以把指定时间点渲染成一张缩略图拼图，方便检查画面。
