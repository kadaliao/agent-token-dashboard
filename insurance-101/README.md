## 内容

- **开场**：一张 30 万的账单砸到"你"身边 → 小概率、大损失 → 片名
- **01 一群人的约定**：一千人各出 300 元组成资金池；"用每个人确定的小支出，换掉不确定的大损失"；大数法则（真实随机模拟）；保费里的赔付、运营成本和利润
- **02 没出事，就亏了吗**：灭火器类比；有无保险的家庭财富曲线；返还型保险拆成"保障 + 储蓄"
- **03 四类保险，各管一件事**：家庭风险中枢图；医保账单拆解（起付线、报销比例、封顶线、目录外）与医疗险的补位、免赔额；重疾险用一笔钱补收入；意外险；定期寿险；报销型 vs 给付型
- **04 四个常见误区**：先给孩子买；有医保就够了；保险都不赔（如实告知、等待期）；越贵越多越好
- **05 从哪里开始**：配置顺序、保费预算、签字前看清三件事
- **尾声**：一千个人连成一张网，接住坠落的那个人 ——"最坏的那一天，家还在。"

## 重新渲染

依赖：Node 20+、Python 3 + numpy、ffmpeg。

```bash
npm ci                          # skia-canvas
tools/fetch_fonts.sh            # 思源宋体 / 思源黑体（Noto CJK SC，SIL OFL）→ fonts/
python3 tools/build_voice.py    # 由 audio/cache 还原逐句配音 → audio/lines/*.wav（旁白没改动时不调用任何 API）
node src/still.mjs x.png a5@放进+1.2 c4+2   # 静帧预览：秒数 / 句子id / 句子id@关键词±偏移
node src/render.mjs --jobs 4    # 4 路并行渲染画面 → out/video.mp4（M2 约 10 分钟）
node src/export.mjs             # 导出混音时间轴、音效点、字幕 → out/
python3 tools/mix.py            # 代码合成配乐与音效，和旁白混音 → out/mix.wav
tools/master.sh                 # 母带（-16 LUFS / 真峰值 -1.5）+ 封装 → out/final.mp4
tools/encode_web.sh             # 压出仓库里的 1080p60 / 720p60 两个版本
```

- 旁白文本在 `src/script.json`：`say` 给 TTS 念（数字写成汉字），`sub` 给字幕显示，`gap` 控制句后停顿。改了哪句，`build_voice.py` 就只重配哪句；这时需要环境变量或 fish 变量 `OPENROUTER_API_KEY`（合成 + Whisper 逐字对齐）。
- 画面在 `src/scenes/*.mjs`，只由时间 t 决定。动作用 `cue('句子id', '关键词')` 对到旁白念到该词的时刻。
- 全局层在 `src/layers.mjs`（背景氛围、章节卡、角标、字幕、暗角与颗粒），基础绘图原语在 `src/engine.mjs`。
- 配乐是 D 大调氛围铺底（Dmaj9 / Bm9 / Gmaj9 / Asus2…）加钟琴点缀、低频和卷积混响；音效（冲击、盖章、金币、护盾等）按画面关键时刻触发。都在 `tools/mix.py` 里，旁白响起时配乐自动压低约 6 dB。

## 数字与口径

片中的金额和比例用来说明原理，片尾有免责声明。

- 千人、1 人、30 万、每人 300 元：思想实验里的假设数字
- 大数法则图：按 1‰ 概率做的伯努利随机模拟（14 条样本路径，±2σ 带）
- 百万医疗险约 1 万元免赔额、年轻人每年几百元；意外险每年一两百元、保额几十万：市面主流产品的常见区间
- 健康险等待期 30~180 天（医疗险常见 30 天，重疾险常见 90~180 天）
- 重疾险保额覆盖 3~5 年收入、保障型保费约占家庭年收入 5%~10%：行业常见经验，片中标注为"常见的建议 / 经验"
- 医保账单各段比例：只示意制度结构，不代表任何地区的真实数据

这些是行业常见口径，没有逐条对照具体产品的条款或某地医保政策；片子仅作科普，不构成产品推荐。
